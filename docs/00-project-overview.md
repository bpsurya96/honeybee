# 00 - Project Overview

## Vision
HoneyBee Learning is a parent-focused, personalised learning journey platform for young children aged newborn to 5 years.

## Mission
Empower parents with the knowledge and tools to support their child's early learning journey, one activity at a time.

## Target Users
- Primary: Parent or caregiver of a young child
- Secondary: Child (0-5 years)

## Core Concept
Parent -> Child Profile -> Purchased Learning Products -> Activities -> Skills -> Activity Completion -> Progress -> Personalised Recommendations -> AI Learning Coach -> Next Activity / Next Product

## Key Principles
1. Structured over generative - All learning data is human-curated, not AI-invented
2. Parent-first - The UI serves parents; content serves children
3. Incremental - Build phase by phase; never over-engineer prematurely
4. Privacy-by-design - Children's data is sensitive; collect only what is necessary
5. AI as assistant - AI explains and guides, it does not define the learning system

## Target Age Range
Initial: Newborn to 5 years

Age/Stage bands:
- 0-6 months
- 6-12 months
- 1-2 years
- 2-3 years
- 3-4 years
- 4-5 years

## Platform Strategy
Phase 1 (now): Mobile-first responsive web app / PWA
Future: React Native mobile app consuming same backend APIs
